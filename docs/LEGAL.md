# exam-uncheat 법·개인정보 메모

> 공개 자료를 바탕으로 정리한 것이며 **법률 자문이 아닙니다.** 기관이 도입하기 전에는 법률 검토를 받으세요. (작성 2026-11-17)

## 1. 재밍(전파 차단)은 하지 않습니다
- 전파법 제29조①: 전파자원은 혼신·간섭 등을 일으켜 타인의 전파이용을 방해 또는 차단하지 않도록 이용되어야 합니다.
- 같은 조 ③항의 전파차단장치 사용 예외는 경호, 국가안전보장 군사활동, 대테러, 공항, 원자력시설 방호와 관련 경찰활동입니다. **시험장은 예외 목록에 없습니다** (2026-10-22 시행본 기준). [조문](https://lawplayer.com/kr/article/001732/002900)
- 제29조⑧·제84조 1의2호: 인가 없이 전파차단장치를 제조·수입·판매하면 3년 이하 징역 또는 3천만원 이하 벌금. [제84조](https://lbox.kr/statute/%EC%A0%84%ED%8C%8C%EB%B2%95/%EB%B3%B8%EB%AC%B8%20%3E%20%EC%A0%9C9%EC%9E%A5%20%3E%20%EC%A0%9C84%EC%A1%B0)
- 따라서 이 저장소에는 차단·교란·송신 코드가 없고, `tools/no_tx_check.py`가 그런 코드를 CI에서 거부합니다. 확장 지점은 [문서만](../ext/authorized-countermeasure/README.md) 둡니다.

## 2. 수신만, 내용은 보지 않습니다
- BLE는 패시브 스캔(스캔 요청 미송신), Wi-Fi는 무차별 수신만. 연결·주입·디인증 없음.
- 해석 대상은 관리 프레임(비콘·프로브)과 BLE 광고뿐입니다. 데이터 프레임은 페이로드를 즉시 버리고 개수·길이·RSSI만 셉니다. 복호화하지 않습니다.
- 통신비밀보호법상 문제를 줄이기 위한 설계지만, 적용 여부는 **법률 검토가 필요**합니다.

## 3. 개인정보
- 기기 주소·SSID·기기 이름은 다른 정보와 결합하면 개인 식별에 쓰일 수 있습니다.
- 허브는 저장 전에 주소를 세션 HMAC으로 가명화하고, SSID·이름을 가립니다. 세션이 끝나면 키를 폐기해 다른 세션과 연결할 수 없습니다.
- 외부 전송 기능이 없습니다. 기본 보존 기간은 **30일**, 이후 자동 삭제(`exam-uncheat purge`, 허브 시작 시 자동 실행).
- 조치 기록에 실명·수험번호를 입력하지 마세요. 세션 정보 필드는 시험명·시험장·고사실·교시만 받습니다.
- 시행기관이 쓰려면 수험생 고지와 처리 근거를 기관이 검토해야 합니다.
- 얼굴인식·영상 촬영 기능이 없습니다.

## 4. 장비와 KC(적합성평가)
- 적합성평가를 받지 않은 무선 기자재를 판매하거나 판매 목적으로 제조·수입하면 전파법 제84조 5호 처벌 대상입니다.
- 개인 사용 목적 반입은 모델당 1대 면제 등 제도가 있습니다. [국립전파연구원 FAQ](https://www.rra.go.kr/ko/notice/D_e_faq2_1.do?fa_category=compt&fa_type=b)
- 기관·학교는 국내 정식 유통·KC 표시 제품을 구매하세요. 송신 가능한 장비(HackRF 등)는 수신 용도로만 쓰세요.

## 5. 시험장 반입
- 시험 시행기관의 승인 없이 센서·허브를 시험실에 설치·반입하지 마세요. 수능 고사장은 수험생뿐 아니라 감독관도 전자기기 반입이 금지된다는 보도가 있습니다([매일경제 2023-11-17](https://www.mk.co.kr/news/society/10877949)).
