# 법적 권한 기관용 대응장치 확장 지점 — 문서만

**이 디렉터리에는 코드가 없고, 앞으로도 송신·차단·교란 코드를 받지 않습니다.**

## 현재 상태
- 현행 전파법 제29조③의 전파차단장치 사용 예외에 **시험장은 포함되어 있지 않습니다**(2026-10-22 시행본 기준). 따라서 현재 어떤 시험 시행기관도 이 저장소로 대응장치를 제어할 수 없습니다.
- 전파차단장치를 인가 없이 제조·수입·판매하면 처벌 대상입니다(제29조⑧, 제84조 1의2호). 자세한 내용은 [docs/LEGAL.md](../../docs/LEGAL.md).

## 향후 법령이 바뀐다면 지킬 원칙
1. 허브는 **읽기 전용 내보내기**(단서·원장 export)만 제공합니다. 대응장치에 명령을 보내는 기능은 이 저장소가 아니라, 인가 장비를 운용하는 기관의 시스템이 책임집니다.
2. 연동은 기관이 자체 인가·감독 절차 안에서 별도 저장소로 구현합니다.
3. 사람이 결정합니다. 허브의 단서가 대응장치를 자동으로 작동시키는 구조는 만들지 않습니다.
